# Quest Lines — ผจญภัยฝึกภาษาอังกฤษ (โปรเจกต์แบบสแตนด์อโลน)

โปรเจกต์นี้คือเกมตัวเดียวกับที่คุณเล่นในแชท แต่ปรับให้ **ทำงานได้ด้วยตัวเอง นอกเว็บ Claude.ai**
โดยเพิ่ม backend เล็กๆ ของตัวเองที่เรียก Anthropic API โดยตรง (ใช้ API key ของคุณเอง)
และเพิ่มไฟล์ที่จำเป็นสำหรับทำให้ "ติดตั้งเป็นแอป" บนมือถือได้ (PWA)

## โครงสร้างไฟล์

```
quest-lines-app/
├── public/
│   ├── index.html         ← ตัวเกมทั้งหมด (HTML+CSS+JS ไฟล์เดียว)
│   ├── manifest.json       ← ทำให้ "Add to Home Screen" กลายเป็นแอปได้
│   ├── service-worker.js   ← แคชไฟล์ไว้ เปิดได้แม้เน็ตช้า/หลุด
│   └── icons/              ← ไอคอนแอป
├── api/
│   └── claude.js           ← เซิร์ฟเวอร์เล็กๆ ที่เรียก Claude API แทนหน้าเว็บ (เก็บ API key ให้ปลอดภัย)
├── package.json
└── .env.example
```

**สำคัญ:** ฟีเจอร์ AI ในเกม (แต่งเนื้อเรื่อง / สร้างมอนสเตอร์ / วาดภาพพิกเซล) เดิมทีใช้ความสามารถพิเศษที่มีเฉพาะในหน้า Artifact ของ Claude.ai
เมื่อเอาออกมาทำเป็นแอปของตัวเอง โค้ดจึงถูกปรับให้เรียก **Anthropic API ของคุณเอง** ผ่านไฟล์ `api/claude.js` แทน — นี่คือเหตุผลที่ต้องมี "เซิร์ฟเวอร์" เล็กๆ ส่วนนี้ (ไม่ใช่แค่ไฟล์ HTML เฉยๆ)

---

## ขั้นตอนที่ 1: ขอ Anthropic API Key

1. ไปที่ https://console.anthropic.com/settings/keys
2. สมัคร/ล็อกอิน แล้วกด "Create Key"
3. คัดลอกคีย์เก็บไว้ (จะขึ้นต้นด้วย `sk-ant-...`)
4. **ห้าม** ใส่คีย์นี้ในโค้ดฝั่งหน้าเว็บ (`public/index.html`) เด็ดขาด ใส่เฉพาะในตัวแปรสภาพแวดล้อม (environment variable) ของเซิร์ฟเวอร์เท่านั้น

ค่าใช้จ่าย: คิดตามการใช้งานจริง (pay-as-you-go) ดูราคาปัจจุบันที่ https://docs.claude.com — ปกติเกมลักษณะนี้ใช้ต้นทุนต่อรอบเล่นไม่กี่สตางค์ถึงไม่กี่บาท

## ขั้นตอนที่ 2: Deploy ขึ้นเว็บ (แนะนำ Vercel — ฟรี และตั้งค่าไม่ยุ่งยาก)

1. สร้างบัญชีที่ https://vercel.com (ล็อกอินด้วย GitHub ได้เลย)
2. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repo ใหม่ (หรือใช้ Vercel CLI: `npm i -g vercel` แล้วรัน `vercel` ในโฟลเดอร์นี้)
3. ใน Vercel: New Project → เลือก repo นี้ → กด Deploy
4. หลัง deploy ครั้งแรก ไปที่ Project Settings → Environment Variables → เพิ่ม:
   - Name: `ANTHROPIC_API_KEY`
   - Value: คีย์ที่ได้จากขั้นตอนที่ 1
5. กด Redeploy อีกครั้งเพื่อให้ค่าตัวแปรมีผล
6. คุณจะได้ลิงก์ เช่น `https://quest-lines-yourname.vercel.app` — เปิดลิงก์นี้แล้วเกมควรทำงานได้เต็มรูปแบบ

> ใช้ Netlify แทนก็ได้: ย้ายไฟล์ `api/claude.js` ไปที่ `netlify/functions/claude.js` และปรับ signature ของฟังก์ชันตามเอกสาร Netlify Functions (โครงสร้างคล้ายกันมาก)

## ขั้นตอนที่ 3: ติดตั้งเป็น "แอป" บนมือถือ (ทำได้ทันที ไม่ต้องขึ้น App Store)

หลัง deploy เสร็จ เปิดลิงก์เว็บของคุณบนมือถือ:

- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → "Add to Home screen" / "ติดตั้งแอป" → จะได้ไอคอนแอปจริงบนหน้าจอ เปิดแบบเต็มจอไม่มีแถบ URL
- **iPhone (Safari):** เปิดลิงก์ → กดปุ่มแชร์ 🔗 → "Add to Home Screen" → ได้ไอคอนแอปเช่นกัน

นี่คือ **Progressive Web App (PWA)** — ใช้งานเหมือนแอปจริง มีไอคอน เปิดเต็มจอ เก็บข้อมูล (เลเวล/ทอง/คำศัพท์) ในเครื่องได้ และเปิดได้แม้เน็ตไม่เสถียร (ยกเว้นตอนขอเนื้อเรื่อง/มอนสเตอร์ใหม่ซึ่งต้องใช้เน็ต)

## ขั้นตอนที่ 4 (ถ้าอยากได้ไฟล์ .apk / ขึ้น Google Play หรือ App Store จริงๆ)

โปรเจกต์นี้พร้อมสำหรับสองทางเลือกนี้:

**ทางเลือก A — PWABuilder (ง่ายที่สุด สำหรับ Android):**
1. ไปที่ https://www.pwabuilder.com
2. ใส่ลิงก์เว็บที่ deploy ไว้ (จากขั้นตอนที่ 2)
3. กด "Package for Stores" → เลือก Android → ดาวน์โหลดไฟล์ `.aab`/`.apk` → อัปโหลดขึ้น Google Play Console (ต้องสมัครบัญชีนักพัฒนา ค่าธรรมเนียมครั้งเดียวประมาณ $25)
4. สำหรับ iOS จะได้โปรเจกต์ Xcode ไปเปิดต่อบน Mac (ต้องมีบัญชี Apple Developer ปีละ $99)

**ทางเลือก B — Capacitor (ถ้าอยากคุมโค้ด native เพิ่มเติมเอง):**
```bash
npm install @capacitor/core @capacitor/cli
npx cap init "Quest Lines" "com.yourname.questlines"
npx cap add android   # ต้องมี Android Studio
npx cap add ios        # ต้องมี Xcode (Mac เท่านั้น)
npx cap copy
npx cap open android   # หรือ ios
```
จากนั้น build/run จาก Android Studio หรือ Xcode ตามปกติ แล้วอัปโหลดขึ้นสโตร์

## หมายเหตุด้านความปลอดภัย

- API key อยู่ในไฟล์ `api/claude.js` ฝั่งเซิร์ฟเวอร์เท่านั้น ไม่ถูกส่งไปหน้าเว็บ ปลอดภัยต่อการเผยแพร่แอปสาธารณะ
- ถ้าจะปล่อยให้คนอื่นเล่นเยอะๆ ควรพิจารณาใส่ rate-limit ที่ `api/claude.js` เพื่อคุมค่าใช้จ่าย (เช่น จำกัดจำนวนครั้ง/ผู้ใช้/วัน)
- ข้อมูลผู้เล่น (เลเวล/ทอง/คำศัพท์/ความสำเร็จ) เก็บด้วย `localStorage` ในเครื่องผู้เล่นแต่ละคน ไม่ได้ส่งขึ้นเซิร์ฟเวอร์ ถ้าอยากทำระบบบัญชีผู้ใช้ข้ามเครื่อง จะต้องเพิ่มฐานข้อมูลเอง (เช่น Supabase, Firebase)
